# Persona 5 Royal 4:3 Aspect Ratio Patch

Work in progress. Native 4:3 for **Persona 5 Royal**, aimed at the **Retroid Pocket Nova** (4.5", 1280x960) and other 4:3 displays. Part of the [Nova 4:3 collection](https://jevonlipsey.github.io/nova-43aspect/).

The patcher will ship only our own patch logic and modify your own copy of the game. **No game code is redistributed.**
